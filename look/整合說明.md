## 🚀 使用步驟

### 1. 安裝依賴
```bash
cd frontend
flutter pub get
```

### 2. 執行應用
```bash
flutter run
```

### 3. 使用功能
1. 開啟應用後，點擊「拍照辨識」功能卡片
2. 等待模型載入完成（首次載入需要幾秒鐘）
3. 選擇「選擇圖片」或「拍照」
4. 選擇圖片後，點擊「開始辨識」
5. 查看辨識結果

## ⚠️ 注意事項

### 模型輸出格式
目前 `_processOutputs` 方法中的實作是簡化版本，可能需要根據實際的 ONNX 模型輸出格式進行調整。

如果辨識結果不正確，可能需要：
1. 檢查模型的實際輸出格式
2. 調整 `_processOutputs` 方法中的解析邏輯
3. 確認輸出張量的維度和順序

### 平台支援
- ✅ Android: 完全支援
- ✅ iOS: 需要額外配置（可能需要調整）
- ⚠️ Web: ONNX Runtime 在 Web 上的支援可能有限

### 性能優化
- 首次載入模型需要 2-5 秒
- 每張圖片辨識需要 0.5-2 秒（取決於手機性能）
- 記憶體使用約 200-500 MB

## 🔧 疑難排解

### 問題 1: 模型載入失敗
**解決方法：**
- 確認 `assets/models/best.onnx` 檔案存在
- 確認 `pubspec.yaml` 中的 assets 路徑正確
- 執行 `flutter clean` 後重新 `flutter pub get`

### 問題 2: 辨識結果為空
**可能原因：**
- 模型輸出格式與預期不符
- 需要調整 `_processOutputs` 方法

**解決方法：**
- 檢查模型輸出的實際格式
- 調整解析邏輯

### 問題 3: 依賴套件安裝失敗
**解決方法：**
- 確認 Flutter SDK 版本符合要求（>=3.0.0）
- 檢查網路連線
- 嘗試使用 `flutter pub cache repair`
