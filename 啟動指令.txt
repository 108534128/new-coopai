=== 後端啟動 ===

python run.py

=== 前端啟動（瀏覽器）===
cd /d E:\Users\acer\Desktop\newproct\frontend
flutter pub get
flutter run -d chrome

=== 前端啟動（手機 USB）===
cd /d E:\Users\acer\Desktop\newproct\frontend
flutter pub get
flutter run

=== 前端啟動（手機 Web）===
cd /d E:\Users\acer\Desktop\newproct\frontend
flutter pub get
flutter run -d chrome --web-hostname 0.0.0.0 --web-port 8080
手機瀏覽器訪問：http://電腦IP:8080

=== 構建 Android APK ===
cd /d E:\Users\acer\Desktop\newproct\frontend
set GRADLE_USER_HOME=E:\.gradle
flutter pub get
flutter build apk --debug
APK位置：build\app\outputs\flutter-apk\app-debug.apk

=== 查看電腦 IP ===

=== 檢查連接設備 ===

=== 資料庫連接問題 ===
如果出現資料庫連接錯誤，請：
1. 確認 ngrok 隧道正在運行（如果使用 ngrok）
2. 或修改 backend/app.py 中的資料庫連接字串
3. 或創建 backend/.env 文件設置 DATABASE_URL
