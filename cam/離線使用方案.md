# 📱 離線使用方案 - 模型內建在 APP 中

## 🎯 概述

這個方案讓組員**完全離線使用**影像辨識功能，不需要連接任何伺服器。模型會直接內建在 APP 中，所有辨識都在手機上執行。

### ✅ 優點
- **完全離線**：不需要網路連接
- **速度快**：直接在手機上執行，無需等待網路傳輸
- **隱私保護**：圖片不會上傳到任何伺服器
- **穩定可靠**：不依賴網路連線品質

### ⚠️ 缺點
- **APP 體積較大**：模型檔案約 50-100 MB
- **首次載入較慢**：需要載入模型到記憶體
- **需要更新模型時**：需要重新發布 APP

### 4. 實作辨識功能

#### 載入模型和資料

```dart
import 'dart:io';
import 'dart:convert';
import 'package:flutter/services.dart';
import 'package:onnxruntime/onnxruntime.dart';
import 'package:image/image.dart' as img;

class ImageRecognition {
  OrtSession? _session;
  OrtEnv? _env;
  List<String>? _classes;
  Map<String, String>? _chineseMap;
  Map<String, String>? _labelFixes;
  
  // 載入模型和資料
  Future<void> initialize() async {
    // 1. 載入 ONNX 模型
    _env = OrtEnv();
    _session = OrtSession.fromAsset(_env!, 'assets/models/best.onnx');
    
    // 2. 載入類別清單
    final classesJson = await rootBundle.loadString('assets/data/classes.json');
    _classes = List<String>.from(json.decode(classesJson));
    
    // 3. 載入中英文對應表
    final chineseJson = await rootBundle.loadString('assets/data/chinese_map.json');
    _chineseMap = Map<String, String>.from(json.decode(chineseJson));
    
    // 4. 載入標籤修正表
    final fixesJson = await rootBundle.loadString('assets/data/label_fixes.json');
    _labelFixes = Map<String, String>.from(json.decode(fixesJson));
  }
  
  // 辨識圖片
  Future<Map<String, dynamic>> recognize(File imageFile) async {
    if (_session == null) {
      throw Exception('模型尚未載入，請先呼叫 initialize()');
    }
    
    // 1. 讀取並預處理圖片
    final imageBytes = await imageFile.readAsBytes();
    final image = img.decodeImage(imageBytes)!;
    
    // 調整大小為 640x640（模型輸入尺寸）
    final resized = img.copyResize(image, width: 640, height: 640);
    
    // 轉換為模型輸入格式（RGB，正規化到 0-1）
    final input = _preprocessImage(resized);
    
    // 2. 執行模型推理
    final inputs = {
      'images': OrtValueTensor.createTensorWithDataAsList(
        [input],
        [1, 3, 640, 640],
        OrtTensorType.ortTensorTypeFloat,
      )
    };
    
    final outputs = _session!.run(OrtValueTensor.createTensorWithDataAsList(
      inputs.values.toList(),
      inputs.keys.toList(),
    ));
    
    // 3. 處理輸出結果
    final detections = _processOutputs(outputs);
    
    // 4. 應用標籤修正
    final fixedDetections = detections.map((det) {
      final rawName = _classes![det['class_id']];
      final fixedName = _labelFixes![rawName] ?? rawName;
      final chineseName = _chineseMap![fixedName] ?? fixedName;
      
      return {
        'class_id': det['class_id'],
        'raw_name': rawName,
        'fixed_name': fixedName,
        'chinese_name': chineseName,
        'confidence': det['confidence'],
        'bbox': det['bbox'],
      };
    }).toList();
    
    // 5. 統計數量
    final counts = <String, int>{};
    for (var det in fixedDetections) {
      final name = det['chinese_name'] as String;
      counts[name] = (counts[name] ?? 0) + 1;
    }
    
    // 6. 生成訊息
    final message = counts.entries
        .map((e) => '${e.value} 個 ${e.key}')
        .join(', ');
    
    return {
      'message': '有 $message',
      'count': fixedDetections.length,
      'ingredients': counts,
      'detections': fixedDetections,
    };
  }
  
  // 預處理圖片（轉換為模型輸入格式）
  List<List<List<List<double>>>> _preprocessImage(img.Image image) {
    // 這裡需要將圖片轉換為 [1, 3, 640, 640] 的格式
    // 具體實作取決於 ONNX 模型的輸入格式
    // 這是一個簡化版本，實際需要根據模型調整
    // ...
    return [];
  }
  
  // 處理模型輸出
  List<Map<String, dynamic>> _processOutputs(List<OrtValue> outputs) {
    // 解析 YOLO 模型的輸出格式
    // 通常包含：檢測框座標、類別 ID、信心度
    // 這是一個簡化版本，實際需要根據模型輸出調整
    // ...
    return [];
  }
}
```

#### 使用範例

```dart
class MyApp extends StatefulWidget {
  @override
  _MyAppState createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> {
  final _recognizer = ImageRecognition();
  bool _isInitialized = false;
  
  @override
  void initState() {
    super.initState();
    _initializeRecognizer();
  }
  
  Future<void> _initializeRecognizer() async {
    try {
      await _recognizer.initialize();
      setState(() {
        _isInitialized = true;
      });
    } catch (e) {
      print('初始化失敗: $e');
    }
  }
  
  Future<void> _recognizeImage(File imageFile) async {
    if (!_isInitialized) {
      print('模型尚未載入');
      return;
    }
    
    try {
      final result = await _recognizer.recognize(imageFile);
      print('辨識結果: ${result['message']}');
      print('食材清單: ${result['ingredients']}');
    } catch (e) {
      print('辨識失敗: $e');
    }
  }
  
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('食材辨識')),
      body: Center(
        child: _isInitialized
            ? Text('模型已載入，可以開始辨識')
            : CircularProgressIndicator(),
      ),
    );
  }
}
```

## 📋 檔案說明

### 1. best.onnx / best.tflite
- **用途**：訓練好的影像辨識模型
- **大小**：約 50-100 MB
- **格式**：ONNX（推薦）或 TFLite
- **輸入**：640x640 RGB 圖片
- **輸出**：檢測框、類別 ID、信心度

### 2. classes.json
- **用途**：類別名稱清單
- **格式**：JSON 陣列，26 個類別
- **範例**：
```json
[
  "tomato",
  "broccoli",
  "onion",
  ...
]
```

### 3. chinese_map.json
- **用途**：英文類別名稱轉換為中文
- **格式**：JSON 物件
- **範例**：
```json
{
  "tomato": "番茄",
  "cabbage": "高麗菜",
  "carrot": "紅蘿蔔"
}
```

### 4. label_fixes.json
- **用途**：修正模型識別錯誤
- **格式**：JSON 物件
- **範例**：
```json
{
  "tomato": "avocado",    // 如果模型識別為 tomato，實際應該是 avocado
  "beans": "cabbage"      // 如果模型識別為 beans，實際應該是 cabbage
}
```

## 🔧 技術細節

### 模型輸入格式
- **尺寸**：640 x 640 像素
- **顏色**：RGB
- **數值範圍**：0.0 - 1.0（需要正規化）
- **格式**：[批次, 通道, 高度, 寬度] = [1, 3, 640, 640]

### 模型輸出格式
YOLO 模型通常輸出：
- **檢測框座標**：x1, y1, x2, y2（相對於圖片尺寸）
- **類別 ID**：0-25（對應 classes.json 的索引）
- **信心度**：0.0 - 1.0

### 處理流程

1. **載入圖片** → 讀取檔案
2. **預處理** → 調整大小為 640x640，轉換為 RGB，正規化
3. **模型推理** → 輸入模型，取得輸出
4. **後處理** → 解析檢測框，過濾低信心度結果
5. **應用修正** → 使用 label_fixes.json 修正錯誤識別
6. **轉換中文** → 使用 chinese_map.json 轉換為中文
7. **統計數量** → 計算每種食材的數量
8. **生成訊息** → 組成可顯示的文字

## ⚠️ 注意事項

### 模型更新
如果模型有更新：
1. 重新執行 `export_for_flutter.py`
2. 將新的 `best.onnx` 替換舊的
3. 組員需要重新編譯 APP

### 性能優化
- **首次載入**：模型載入需要 2-5 秒
- **推理速度**：每張圖片約 0.5-2 秒（取決於手機性能）
- **記憶體使用**：約 200-500 MB

### 相容性
- **Android**：支援 ONNX 和 TFLite
- **iOS**：主要支援 ONNX，TFLite 需要額外設定
- **建議**：使用 ONNX 格式，相容性最好

## 🆚 離線方案 vs 線上方案

| 特性 | 離線方案 | 線上方案（API 伺服器） |
|------|---------|---------------------|
| **網路需求** | ❌ 不需要 | ✅ 需要 |
| **速度** | ⚡ 快（本地執行） | 🐌 較慢（網路傳輸） |
| **APP 大小** | 📦 大（+50-100 MB） | 📦 小 |
| **隱私** | 🔒 完全本地 | ⚠️ 圖片上傳伺服器 |
| **穩定性** | ✅ 不依賴網路 | ⚠️ 依賴網路品質 |
| **更新模型** | 🔄 需重新發布 APP | ✅ 伺服器更新即可 |
| **適用場景** | 個人使用、離線環境 | 團隊協作、集中管理 |
