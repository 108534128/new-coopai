# 語音功能使用說明

## 概述
我們已經在 Recipe Walkthrough Screen（食譜演練頁面）中成功整合了語音功能，包括：
1. **語音朗讀（TTS）** - 自動朗讀食譜步驟內容
2. **語音控制** - 使用語音指令控制食譜步驟導航

## 功能特點

### 🔊 語音朗讀功能（TTS）
- **啟用方式**: 點擊右上角的音量按鈕（📢）
- **自動朗讀**: 切換步驟時自動朗讀新步驟內容
- **手動朗讀**: 在步驟內容區域點擊「朗讀步驟」按鈕
- **歡迎語音**: 進入頁面時自動播放歡迎訊息

### 🎤 語音控制功能
- **啟用方式**: 點擊右上角的麥克風按鈕（🎤）
- **喚醒詞**: 說出「嘿廚師」來啟動語音指令模式
- **支援的語音指令**:
  - 「下一步」/ 「下一頁」→ 前往下一個步驟
  - 「上一步」/ 「上一頁」→ 回到上一個步驟
  - 「重複」/ 「重複步驟」→ 重新朗讀當前步驟
  - 「停止」→ 停止計時器
  - 「繼續」→ 恢復暫停的計時器
  - 「完成」→ 退出食譜演練

## 使用界面

### AppBar 按鈕
1. **TTS 按鈕** (🔊/🔇)
   - 綠色：語音朗讀已啟用
   - 灰色：語音朗讀已關閉

2. **語音控制按鈕** (🎤/🎤)
   - 紅色：語音控制已啟用
   - 灰色：語音控制已關閉

### 步驟內容區域
- **語音狀態指示器**: 顯示當前朗讀狀態和語音控制狀態
- **語音功能面板**: 包含手動朗讀按鈕和語音指令提示
- **測試按鈕**: 橙色「測試語音」按鈕用於開發測試

### 底部導航區域
- **語音控制提示**: 顯示語音控制狀態
- **導航按鈕**: 上一步/下一步/完成按鈕

## 測試方法

### 1. TTS 功能測試
1. 進入任何食譜的演練頁面
2. 點擊右上角音量按鈕啟用 TTS
3. 確認聽到歡迎語音
4. 滑動到下一步，確認自動朗讀
5. 點擊「朗讀步驟」按鈕測試手動朗讀

### 2. 語音控制測試
1. 點擊右上角麥克風按鈕啟用語音控制
2. 說出「嘿廚師」啟動指令模式
3. 說出「下一步」測試步驟切換
4. 說出「上一步」測試返回功能
5. 說出「重複」測試重新朗讀功能

### 3. 開發測試
- 點擊橙色「測試語音」按鈕模擬喚醒詞
- 觀察 Debug 輸出確認語音識別結果
- 測試各種語音指令的響應

## 注意事項

1. **權限要求**: 需要麥克風和語音識別權限
2. **網路連線**: 某些 TTS 功能可能需要網路連線
3. **語言設置**: 支援繁體中文語音識別和合成
4. **背景雜音**: 在安靜環境中測試以獲得最佳效果
5. **發音清晰**: 清楚地說出指令詞彙

## 故障排除

### 常見問題
1. **語音無法識別**: 檢查麥克風權限和網路連線
2. **TTS 無聲音**: 檢查音量設置和音頻輸出設備
3. **指令不響應**: 確認已正確啟用語音控制模式
4. **喚醒詞無效**: 嘗試更清楚地說出「嘿廚師」

### Debug 輸出
- 觀察 Console 中的語音服務 Debug 訊息
- 檢查 `🎤`、`🔊`、`✅`、`❌` 等標記的日誌
